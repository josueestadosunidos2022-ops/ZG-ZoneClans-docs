This reference was checked against **server 1.1.4** source. `config/zonaclans-common.toml` is generated by Forge and contains the editable settings. Stop the server before editing it; back up the world first. Clan names, ranks, wars and treasury live in saved world data. / Esta guía se contrastó con las fuentes del **servidor 1.1.4**. The keys above are nested under TOML groups: `general` (`broadcastMembership`, `broadcastPayments`, `broadcastWar`, `decoratedMessages`, `historyRows`, `maxClansPerPlayer`, `nameMaxLength`, `nameMinLength`, `topRows`), `economy` (`transferMax`, `treasuryMax`), `wars` (`openToWars`, `warTargetsOnly`), `permissions` (`requirePermissionClan`, `requirePermissionCreate`), and `prizes` (all prize time, position and amount keys). These are server controls; the client does not set banking or permission rules. / Las claves están dentro de esos grupos TOML. Son controles de servidor; el cliente no fija reglas bancarias ni permisos.

`requirePermissionClan` checks `zoneclans.command.clan`; `requirePermissionCreate` checks `zoneclans.command.create`. Assign these with a compatible permission provider through ZoneCore, such as ZoneRanks. `dayOfWeek` uses 1=Monday through 7=Sunday, and `hour`/`minute` use the server's local time. / `requirePermissionClan` revisa `zoneclans.command.clan`; `requirePermissionCreate` revisa `zoneclans.command.create`. Concédeselos mediante un proveedor de permisos compatible con ZoneCore, como ZoneRanks. `dayOfWeek` usa 1=lunes y 7=domingo; la hora corresponde a la zona local del servidor.

The generated TOML comments and the protected release should be checked together before production use. Do not commit real server data, credentials or account databases. / Antes de usarlo en producción, comprueba los comentarios del TOML generado junto con la entrega protegida. No publiques datos reales del servidor ni credenciales.
